# Приложение для сравнения двух текстов

## Задача

Система анализа и сравнения текстов на PHP

- [x] Текстовое поле, где пользователь вводит первую версию текста.
- [x] Текстовое поле, где пользователь вводит вторую версию текста.
- [x] Кнопка “Сравнить”
- [x] При нажатии кнопку появляется вторая версия текста с изменениями относительно первого текста.
- [x] Новые предложения должны быть выделены светло-зеленым цветом.
- [x] Измененные предложения должны быть выделены желтым цветом.
- [x] Удаленные предложения должны быть выделены красным цветом.
- [x] При наведении курсора мыши на измененное (желтое) предложение оно должно заменяться на первую версию (при пропадании фокуса с измененного предложения опять видна новая версия).
- [x] Не использовать готовые php библиотеки для выполнения данного задания.

## Makefile

### Доступные команды

| Команда | Описание |
|---|---|
| `make start` | Собрать образы и поднять приложение |
| `make up` | Поднять приложение (без пересборки) |
| `make down` | Остановить приложение |
| `make nginx-logs` | Логи nginx |
| `make php-logs` | Логи php-fpm |
| `make help` | Список всех доступных команд |
